# dnlvocatio.com

Personal portfolio and life site for Daniel Nursen. Built with React, Vite, Tailwind CSS, and TypeScript. Deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev        # http://localhost:8080
```

## Validate

```sh
npx tsc --noEmit   # Type check
npm run lint        # ESLint
npx vite build     # Production build
```

## Deploy

Push to `main` triggers automatic deployment via GitHub Actions.

- Edit files directly within the Codespace and commit and push your changes once you're done.

## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## How can I deploy this project?

Simply open [Lovable](https://lovable.dev/projects/1c8b790a-90ef-4b5a-b595-062155771075) and click on Share -> Publish.

## Can I connect a custom domain to my Lovable project?

Yes, you can!

To connect a domain, navigate to Project > Settings > Domains and click Connect Domain.

Read more here: [Setting up a custom domain](https://docs.lovable.dev/features/custom-domain#custom-domain)
